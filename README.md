# Awesome SGDK [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of awesome SGDK (Sega Genesis Development Kit) tools, libraries, resources and projects for Sega Genesis/Mega Drive development.

[SGDK](https://github.com/Stephane-D/SGDK) is a free and open development kit for the Sega Mega Drive/Genesis. It allows developers to create games and applications for this classic 16-bit console using C language.

## Development Kits and Toolchains

- [SGDK](https://github.com/Stephane-D/SGDK) - The main Sega Genesis Development Kit. A free and open development kit for the Sega Mega Drive.
- [marsdev](https://github.com/andwn/marsdev) - Cross-platform Mega Drive / 32X toolchain with SGDK support.
- [gendev](https://github.com/kubilus1/gendev) - Genesis development environment for Linux.
- [gendev-macos](https://github.com/SONIC3D/gendev-macos) - Genesis/Mega Drive development environment for Mac OS X.
- [sgdk_nix](https://github.com/drojaazu/sgdk_nix) - Makefiles and instructions for using SGDK in *nix environments.
- [megadev](https://github.com/drojaazu/megadev) - A Sega Mega CD development framework in C and 68k assembly.
- [mdk](https://github.com/Mikejmoffitt/mdk) - Barebones Mega Drive development setup.
- [pysega](https://github.com/hansbonini/pysega) - Sega Genesis / Mega Drive development kit (SDK) written in Python.

## IDE and Editor Extensions

- [genesis-code](https://github.com/zerasul/genesis-code) - Visual Studio Code Genesis Development Extension with SGDK support.
- [SEGA_VSCode_Template](https://github.com/pleft/SEGA_VSCode_Template) - Setting up SGDK with Visual Studio Code template project.

## Graphics Tools

- [MAPeD-SPReD](https://github.com/0x8BitDev/MAPeD-SPReD) - Multi-platform development tools including map and sprite editors for Sega Mega Drive (supports SGDK).
- [bmp2bg](https://github.com/pw32x/bmp2bg) - Exports tilemap, tileset, and palette information as C source from 16-color bitmaps.
- [gg2c](https://github.com/pw32x/gg2c) - Command line tool that exports Graphics Gale files to C source files.
- [Turbulence](https://github.com/Kreglar/Turbulence) - Visual asset editor for Sega Genesis development with tilemap and palette support.
- [godot2sgdk](https://github.com/fiddd0/godot2sgdk) - Export assets and data from Godot for SGDK development.
- [SegaGenesis-BMP2HEX](https://github.com/renderedsheep/SegaGenesis-BMP2HEX) - Convert bitmap images into Sega Genesis-compatible hex data.
- [mega-tools](https://github.com/StealthC/mega-tools) - Simple online tools to help understand and learn Sega Genesis development.

## Sound and Music Tools

- [MDSDRV](https://github.com/superctr/MDSDRV) - Sound driver for Sega Mega Drive with SGDK support.
- [mdtracker](https://github.com/corthax/mdtracker) - Native music tracker for Sega Mega Drive/Genesis/Nomad.
- [ZorroTracker](https://github.com/ZorroTrackerDev/ZorroTracker) - Sega Mega Drive / Genesis music tracker.
- [mml2vgm](https://github.com/kuma4649/mml2vgm) - MML compiler that supports YM2612 and SN76489 for VGM format.
- [MDPlayer](https://github.com/kuma4649/MDPlayer) - Multi-platform music player and visualizer.
- [PSGlib](https://github.com/sverx/PSGlib) - Z80 ASM library for SN76489 VGM replay.
- [mega-drive-midi-interface](https://github.com/rhargreaves/mega-drive-midi-interface) - Control the Mega Drive's YM2612 and PSG with MIDI.

## Emulators

- [Genesis-Plus-GX](https://github.com/ekeeke/Genesis-Plus-GX) - Enhanced and accurate Sega 8/16 bit emulator.
- [clownmdemu-core](https://github.com/Clownacy/clownmdemu-core) - Sega Mega Drive emulator that emphasizes portability.
- [clownmdemu-frontend](https://github.com/Clownacy/clownmdemu-frontend) - Reference standalone frontend for ClownMDEmu.
- [jgenesis](https://github.com/jsgroth/jgenesis) - Multi-system emulator including Genesis/Mega Drive support.
- [Nuked-MD](https://github.com/nukeykt/Nuked-MD) - Cycle-accurate Mega Drive emulator.
- [moa](https://github.com/transistorfet/moa) - Emulator for various m68k based computers including Genesis.
- [Geardrive](https://github.com/drhelius/Geardrive) - Sega Mega Drive / Genesis emulator for multiple platforms.

## Debugging and Profiling

- [md-profiler](https://github.com/Tails8521/md-profiler) - Tracing profiler for the Sega MegaDrive/Genesis.
- [svpdev](https://github.com/jdesiloniz/svpdev) - Development tools targeting SEGA's SVP chip.

## Libraries and Engines

- [SGDK_PlatformerStudio](https://github.com/bolon667/SGDK_PlatformerStudio) - Easy-to-use engine to make platformers for Sega Genesis.
- [scorpion-editor-demos](https://github.com/earok/scorpion-editor-demos) - Editor for Scorpion engine with demo games.
- [megapack-megadrive](https://github.com/lab313ru/megapack-megadrive) - Mega Drive compression algorithm.
